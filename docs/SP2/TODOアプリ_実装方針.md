[SP2]TODOアプリ_実装方針

前提 : 同フォルダのTODOアプリ_仕様書.md(SP2版)を前提とする。

# 実装タスク

以下のタスク単位でIssueを切る。
MRはその中の機能単位で切る。

ブランチ名 : issue-{Issue番号}-{内容の英語スラッグ}

※以下は絶対守ってほしいわけではないが、大きく内容がずれないようにして。

# タスク1 - TODO場所の設定・開く

[完了イメージ]
- 起動時に表示するTODOフォルダパスをiniファイルで設定できる
- TODO項目の右クリックメニューから「開く」でフォルダを開ける
- メモ情報の右クリックメニューから「開く」でmdファイルを開ける

# タスク2 - アプリのアイコン変更

[完了イメージ]
- アプリのアイコンが`image/アイコン.ico`になっている

# タスク3 - TODO項目の「本文」廃止

[完了イメージ]
- TODO項目に本文欄が無い
- TODO項目・メモ情報のタイトルが必須入力になっている
  → フォーカスアウト時に未入力なら直前の値に戻る
- メモ情報リストが常に1件以上保持される
  → メモ情報の削除、TODOへの変換は、メモ情報が
    2件以上のときのみ実行可能になっている
- 新規TODO追加時にタイトル「README」のメモが自動追加される
- パンくずリストの祖先判定を_save.jsonの存在確認に変更する
- タイトルnull許容に伴う不要なUI・コンバーターを削除する

# タスク4 - TODO項目の上下レイアウト廃止

[完了イメージ]
- 上半分の表示領域が無くなり、左右のレイアウトになっている
- パンくずリストがウィンドウ最上部に表示されている
- 子TODOリストの右クリックメニューでステータス変更ができる
- TodoDetailEditorのステータス関連(コンボボックス・
  背景トリガー)を削除する

# タスク5 - リスト表示の簡略化

現状のMainWindow.xamlは孫項目までの固定ネストGrid構成。
本タスクで自己参照UserControlへ構造刷新する。

[完了イメージ]
- 子TODO0件、メモ1件の場合、リスト無しでメモが直接表示される
- 子TODO0件、メモ2件以上の場合、メモリストのみが表示される
- 子TODOが1件以上の場合、タブ名が「TODOリスト」
  「NOTEリスト」になっている
- TODOリスト選択時、孫以下も再帰的に表示される
- MainViewModelのChildNode/RebuildChildNodeを廃止し、
  自己参照UserControl内のローカル状態に置き換える

# タスク6 - パンくずリストの仕様変更

タスク4・5の後に対応する。

[完了イメージ]
- 祖先パンくずリストの右に、表示中のTODOタイトルが
  リンク無しで表示される
- さらにその右に、再帰的に表示中のTODO項目が
  リンク付きで一通り表示される
- リンクを押すと、そのTODOが新たな表示位置になる

# タスク7 - リスト表示の見た目修正

タスク4の後に対応する。

[完了イメージ]
- 子TODOリストの項目背景によるステータス表示が無くなっている
- TODO項目の左側にステータスアイコンが表示される
  → `image/未対応.ico`
  → `image/対応中.ico`
  → `image/完了.ico`
- アイコンのダブルクリックでステータスが進む
  (右クリックメニューの「〇〇に変更」と同じ動作)
  → 完了時はダブルクリックしても変化しない
