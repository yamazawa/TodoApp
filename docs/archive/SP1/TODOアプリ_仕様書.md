# 実装順序

# A.モデル設計

各TODOは親子関係を持たせる。

## 各TODOの保持項目

### 根本情報

- タイトル(null指定可能)
- 本文
- ステータス(未対応、対応中、完了)
- メモ情報リスト
  → メモ情報は可変なリスト構造で持つ
  → メモ情報の保持項目は次項
- 子TODOリスト
　→ 子TODOリストは可変なリスト構造で持つ

### 表示用情報

- 現在選択中のタブ
- 現在選択中の子TODO
- 現在選択中のメモ情報

## メモ情報の保持項目

- タイトル(null指定可能)
- 本文

## 注意点

各メモ情報と各子TODO項目は相互に変換可能にする。
※子TODOリストをメモ情報に変換するときは孫以下のTODOも対象に含む。
※孫以下は再帰的に平坦化し、子TODOとメモ情報を全てメモ情報に変換する。
※変換後の項目は変換先リストの末尾に挿入する。
※選択中項目を、挿入した項目に変更する(タブ切替で確認可能)。
※N個挿入された場合は、挿入されたN個の先頭を選択する。

# B. 画面設計

基本的に選択中のTODOを表示する思想にする。
アプリ起動時は設定ファイルに記載されたフォルダパスのTODOを表示。

アプリ内には以下を表示する

## 上半分

### 表示項目

-  選択中TODOのタイトル(1行のテキストボックス)
   → タイトルがnullの場合は濃いグレーで本文の1行目を表示
　 → テキストボックスがフォーカスしたら空文字になって入力可能になる
　 → フォーカスアウト時、未入力ならnullに戻す
-  選択中TODOのステータス(コンボボックスでステータスを変更可能)
-  選択中TODOの本文(N行テキストボックス)
-  選択中TODOのパンくずリスト(親TODOへのリンクにジャンプできる)
   → ファイル構成の親を辿り、以下2条件を満たせば親TODOがあると判定(ファイルの中身は見ない)。
      ①親フォルダのフォルダ名がTODO項目のファイル設計と合致する。
      ②その親フォルダ内に000_README.mdがある。

### レイアウト

-  高さは本文で、上半分の余白を埋めるよう表示。
-  上半分と下半分の初期比率は5:5。
-  上半分と下半分はドラッグ操作で境界を変更可能にする。
-  この比率はアプリ全体設定として保持する。

## 下半分の左側

### 表示項目

-  メモ情報/子TODO のタブ表示
   → メモ情報には個数を(4)のように表示
　 → 子TODOには完了数/総数を(4/6)のように表示
-  選択中TODOのメモ情報リスト ※メモ情報のタブ選択時に表示
-  選択中TODOの子TODOリスト ※子TODOのタブ選択時に表示

### リスト表示詳細(子TODOリスト/メモ情報リスト 共通)

リスト項目にはタイトルを表示。
-  タイトルがnull字はメモの1行目を表示

右クリックメニュー
-  リンク移動[E]
-  追加[A](その項目の下に項目を追加)
-  削除[D](その項目を削除(その項目の子要素もすべて削除))
　→ 削除前に確認ダイアログを表示する
-  名前変更[F2](Dialog表示で入力でタイトルを変更)
-  上へ[Ctrl+↑]
-  下へ[Ctrl+↓]
※リストがフォーカス時は選択項目に対して
　[]記載のキーボード操作で操作可能にして。

### リスト表示詳細(子TODOリスト 固有)

リスト項目は、対応中→未対応→完了の順で自動ソートして並べる。
※上に対応中、下に対応中の場合「下へ」を押したら入れ替わる
※上に対応中、下に未対応の場合「下へ」を押しても上下が入れ替わらない。(自動ソート優先)

右クリックメニュー
-  対応中へ[Z](ステータスが未対応の場合のみ表示)
-  完了へ[C](ステータスが対応中の場合のみ表示)
-  メモ情報へ変換[V] ※右クリックメニューの一番下

### リスト表示詳細(メモ情報リスト 固有)

右クリックメニュー
-  TODO情報へ変換[V] ※右クリックメニューの一番下

### レイアウト

-  下半分の左側と下半分の右側は初期比率が2:8
-  上半分と下半分はドラッグ操作で境界を変更可能にする。

## 下半分の右側

下半分の左側のリストで選択されている 子TODO項目 または メモ情報を表示

### メモ情報の場合

タイトル/本文を上半分のTODO項目のタイトルと本文と同様に表示
※上半分の「タイトル/ステータス/本文」の表示と同じコントロール部品で共通化すること

### 子TODO項目の場合

画面全体の親TODO項目と同様のレイアウトを下半分の右側に表示
※上にタイトル、左下に孫項目リスト、右下に選択中の孫項目詳細
※左下の孫項目リストは、下半分の左側と同様にタブ切替・右クリックメニューを持つ
　→ 下半分の左側と共通のリストボックスコントロールを用意して使い回すこと
※右下の孫項目詳細
　孫項目がTODO項目 : タイトル/ステータス/本文/孫TODOリストの個数(〇/〇)を表示
　孫項目がメモ情報 : タイトル/本文を表示
　※上半分の「タイトル/ステータス/本文」の表示と同じコントロール部品で共通化すること
※上、左下、右下の表示比率は親TODOの表示割合と別に保持する。

# C. ファイル設計

## フォルダ構成

各TODOは親子関係に合わせてフォルダ構成を作成する
※意図として、人が読みやすい形で設計したい。
※Claudeにもそのままファイルパスを渡せば対応して貰えそうな形にしたい。

1_AAA_対応中 ... ①
├ 0_README.md ... ②
├ 1_BBB.md ... ③
├ 2_CCC.md ... ③
├ :
├ 1_DDD ... ①

※子TODOとメモ情報の連番は別々にカウントする(同じ番号が重複してよい)。
※子TODO、メモ情報は共に最大9個までとする。

### ①TODO情報 フォルダ

フォルダ名 : [連番]_[タイトル]_[ステータス]
[連番] : 親フォルダ内での連番を1~9で表現する。(※一番親の場合「1」)
[タイトル] : タイトルの文字列を表示。NULLの場合は「NULL」と表示
[ステータス] : ステータス(未対応、対応中、完了)を表示

### ②TODO情報 のREADME

ファイル名 : 0_README.md (固定名称)
ファイルの内容 : TODO項目の本文をそのまま書く

### ③メモ情報

ファイル名 : [連番]_[タイトル].md
[連番] : 親フォルダ内での連番を1~9で表現する。
[タイトル] : タイトルの文字列を表示。NULLの場合は「NULL」と表示
ファイルの内容 : メモ情報の本文をそのまま書く

### ファイル名に使えない文字の扱い

[タイトル]をファイル名/フォルダ名に使う際、書込時に禁止文字を「_」に置換する。
※禁止文字 : \ / : * ? " < > |
※読込時に元の文字列へ完全復元されないことは仕様として許容する。
※タイトルが文字列として「NULL」の場合とnullの場合が区別できないことも仕様として許容する。

### ④保存情報

ファイル名 : _save.json (固定名称)
※先頭を数字以外にすることで、フォルダ内で常に一番下に来るようにする。
※④保存情報にはTODO単位の表示用情報(選択中タブ/子TODO/メモ情報)を保存する。

### ⑤アプリ全体設定

以下はTODO単位ではなく、アプリ全体で1つ保持する。
- 起動時に表示するTODOのフォルダパス
- 上半分と下半分の比率
- 下半分の左右比率
- 下半分の右側(子TODO項目表示時)の上/左下/右下の比率
保存場所・フォーマットは問わない。

## ファイルとアプリ内モデルの同期

これらのファイルは外部から変更されない前提の設計とする。
(Claudeでもこれらのファイルの変更は制限する設計にする)

数秒おきに非同期でModel内容をファイル出力する仕組みを作成する。
これにより画面内の変更が反映されるようにする。(Backup等は一旦不要)
※アプリ終了時は同期的に保存し、直前の変更を確実に残す。
