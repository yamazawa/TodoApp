# TodoApp

WPF (.NET) + MVVM (CommunityToolkit.Mvvm) で作成する階層型TODO管理デスクトップアプリです。

開発はアジャイルのスプリント単位([SP1]、[SP2]、...)で進めています。
現在の開発ルールは以下を参照してください。

- `docs/ガイドライン.md`

初期仕様(クローズ済み、実装に反映済み)は以下を参照してください。

- `docs/archive/TODOアプリ_仕様書.md`
- `docs/archive/TODOアプリ_実装方針.md`

## 動作環境

- .NET 9 (Windows)

## 実行方法

```powershell
dotnet run --project TodoApp
```

## ビルド方法

```powershell
dotnet build
```
